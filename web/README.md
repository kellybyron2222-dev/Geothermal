# Vite + React + TypeScript + MapLibre

Static frontend for Texas next-gen **county screening** (Phase 1).

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Structure

```text
src/
  App.tsx                 # Shell only (Milestone 0)
  components/             # MapView, CountyList, DetailPanel (stubs)
  types/screening.ts      # Shared screening types
public/data/              # prospects.json / geojson (Milestone 3+)
```

Features are intentionally not built yet. See `docs/red-team-mvp.md` Part 4.
