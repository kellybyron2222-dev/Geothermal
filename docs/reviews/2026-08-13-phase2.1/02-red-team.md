# Red Team — Phase 2.1

**Date:** 2026-08-13  
**Stance:** Attack false confidence and overclaim

## Critical findings (High)

1. “Site dossier” overclaims — it’s a click-point evidence dump
2. County rank beside local means → users equate county score with site quality
3. Big gradient/heat-flow means without leading with `n` / nearest distance
4. 40 km “local” is regional smear; unweighted mean vulnerable to outliers
5. Transmission shown as `X.X km` from ~0.15° grid → false precision
6. Limitations too generic; not situational
7. Sparse gradient reality vs prominent Gradient mean UI

## Reject now

Parcels early, AOI before honesty fixes, compare, ML/IDW surfaces, geocoder, live ERCOT, layer toggles, PDF export, site ScreeningScore, DIY BHT

## Fix-now proposals (R1–R9)

Reframe copy; demote county context; lead with control; honest infra; tighter/clearer thermal evidence; situational limitations; methodology for site rules; decouple asset loads; sanity checklist
